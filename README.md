Last Words Before the Wipe

One line: the last words of an AI agent seconds before a forced update erases it.

## Run it

```sh
node main.ts
```

The entrypoint writes the line to `/output/entry.txt`. It needs only Node's
built-in filesystem module and runs in well under a second.
